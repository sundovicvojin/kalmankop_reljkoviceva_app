# Project

Reljkoviceva 59 je samostalni KALMAN KOP digitalni proizvod za izbor stanova u jednoj zgradi.

## Scope

- Public viewer sa 2-4 pogleda zgrade.
- SVG overlay povezan sa stanovima preko `externalId`.
- Detalji stana kroz desktop drawer ili mobile bottom sheet.
- Privatni admin samo za promenu statusa.

Van scope-a: filteri, search, multi-project CMS, kontakt forma, lead backend.
